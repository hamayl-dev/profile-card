## ✨ Project Overview

The **User Profile Card** is a modern, interactive web component designed to showcase personal or professional profiles with style.
Built using **HTML, CSS, and JavaScript**, this project highlights:

* 🎨 Sleek and responsive design
* 👤 Profile picture, name, and profession
* 🔗 Social media links with interactive buttons
* ⚡ Smooth toggle animations for expanding/collapsing social links
* 📱 Fully responsive on all devices

Perfect for **portfolio projects, personal websites, or UI/UX demos**, this component demonstrates modern front-end development skills with focus on interactivity and clean design.

## 🎯 Features

* 👤 **Profile Information:** Displays user name, profession, and avatar.
* 🔗 **Interactive Social Links:** Supports Instagram, GitHub, Facebook, Dribbble, and LinkedIn.
* ⚡ **Toggle Animation:** Click the menu icon to expand or collapse social media links with smooth animations.
* 📱 **Fully Responsive:** Works seamlessly across mobile, tablet, and desktop screens.
* 🎨 **Clean UI/UX:** Minimalistic design focused on user engagement and readability.

## 🛠️ How to Use / Run Locally

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/User-Profile-Card.git
```

### 2️⃣ Navigate to the Folder

```bash
cd User-Profile-Card
```

### 3️⃣ Open the Project

You can directly open `index.html` in your browser or use **Live Server** for a better experience:

```bash
# In VS Code
Right-click index.html → Open with Live Server
```

### 4️⃣ Customize Profile

* Change the profile picture in `assets/img/cropped_circle_image.png`
* Update name and profession in the HTML file
* Modify social media links in the HTML file
* Adjust styling in `styles.css`
